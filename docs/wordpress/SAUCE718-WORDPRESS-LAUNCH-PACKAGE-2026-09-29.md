## Mobile-first rules

- Keep hero copy short enough to fit above the fold on a phone.
- Use one primary CTA per section.
- Avoid dense multi-column layouts on small screens.
- Keep navigation compact.
- Use strong typography and generous spacing.
- Prefer fast-loading brand visuals over decorative clutter.

## WordPress execution sequence

1. Confirm Sauce718 is on a WordPress.com plan that permits custom-domain connection.
2. Attach blog.sauceapproved.com inside WordPress.
3. Capture the exact DNS values WordPress provides.
4. Add only the blog subdomain DNS record at Spaceship.
5. Verify public DNS propagation.
6. Verify HTTPS and SSL on blog.sauceapproved.com.
7. Set blog.sauceapproved.com as the WordPress primary domain.
8. Build homepage and navigation using the structure above.
9. Confirm mobile rendering.
10. Keep sauceapproved.com and www unchanged for Shopify.
11. Launch the WordPress site only after the custom-domain route is healthy.

## Hard gates

- No paid WordPress purchase without owner authorization.
- No CAPTCHA, MFA, identity-verification, or provider-security bypass.
- No root-domain or www DNS change for WordPress.
- No guessed DNS targets.
