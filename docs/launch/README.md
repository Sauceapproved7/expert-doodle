# Hercules Launch Pack v0.1

This folder contains the customer/business launch material for Hercules Revenue Recovery.

## Included
- positioning
- customer journey
- pricing proposal
- customer-facing security explainer
- support policy
- legal/privacy review checklist

## Launch rule

These documents do not make Hercules launch-ready by themselves. Public launch requires the product, customer boundary, production operations, hardening evidence, billing activation, support/security contacts, and legally required owner actions to be completed and verified.

Pricing is proposed until the billing system is activated. Legal/privacy review remains an owner/counsel boundary where applicable.

The public experience must follow the Hercules Build Standard: distinctive presentation, accurate claims, evidence-backed states, and no placeholder/fake success signals.
