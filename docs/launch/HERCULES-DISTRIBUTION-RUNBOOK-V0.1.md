# Hercules Revenue Recovery — Controlled Distribution Runbook v0.1

## Organic-first rule

Do not scale paid acquisition before the product shows a repeatable path through:
understand -> want -> activate -> pay -> stay.

## Weekly proof engine

One primary proof event per week becomes:
- LinkedIn founder proof post;
- YouTube / long-form walkthrough;
- short vertical proof cut;
- X proof thread;
- SEO article;
- Build Receipt;
- Failure File or recovery note when applicable;
- sales proof asset;
- Trust Center update.

## Initial content sequence

1. Why overdue invoices are not all the same.
2. Build Receipt #001 — three receivables, three safe routes.
3. Why human approval belongs in financial AI workflows.
4. Failure File #001 — what happens when evidence conflicts.
5. Hercules Gauntlet #001 — give Hercules a messy receivables case and make it show the evidence.
6. Founding-pilot invitation.

## Outbound

Target a small named-account list in the initial ICP.

Sequence:
qualified account -> relevant contact -> jurisdiction/marketing check -> personalized message -> limited follow-up -> suppression/opt-out state -> CRM outcome.

No mass spam.

Primary CTA: controlled founding pilot, not "buy now."

## Partners

Priority:
- accountants;
- bookkeepers;
- fractional CFOs;
- consultants;
- accounting/ERP integrators;
- agencies.

Partner CTA:
bring one real workflow for a controlled pilot.

Track:
partner -> attributed lead -> activation -> paid -> retained -> expansion.

## Paid acquisition gate

Paid search/retargeting remains off until:
- demo comprehension is consistent;
- first verified useful action is measured;
- paid conversion exists;
- retention is observable;
- attribution and billing are trustworthy;
- claims/legal/privacy surfaces are ready.
