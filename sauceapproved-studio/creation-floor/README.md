## Hercules build standard
Strong architecture. High-quality execution. Original visual/product identity. Fly presentation. Built to last.

## Two system-wide differentiators
- **Proof Spine** — provenance follows assets through edit, review, export, and publishing handoffs.
- **Creative DNA Guard** — performance evidence can produce recommendations, but cannot silently rewrite Brand Brain.

## Safety and execution contract
Inventory → plan → authorize → execute → verify. Publishing, external analytics, credentials, and unverified rendering remain fail-closed until their runtime evidence and authorization gates are satisfied.
