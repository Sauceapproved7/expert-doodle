# Hercules ChatGPT Plugin

Portable Agent Plugins package for the Hercules remote MCP server.

## Submission gates

- Production MCP: `https://hercules-mcp.onrender.com/mcp`
- Domain challenge is supplied only through `OPENAI_APPS_CHALLENGE`; never commit the challenge token.
- Keep MCP authentication enabled; do not place bearer credentials in this package.
- Initial MCP review requires exactly five positive and three negative cases.
- A reviewer-accessible demo recording URL is required.
- Website, support, privacy, and terms URLs must be live HTTPS URLs identifying the publisher.
- Developer/business identity verification and policy attestations are owner/publisher actions.
- Run the OpenAI tool scan after connecting the production MCP server.

Do not add app references or lifecycle hooks to the public-submission ZIP.
